# Linear Algebra Math Rendering

## Matrices And Vectors

### Compact Matrix Input

```math
A = [[1, 2, 0], [0, 1, 1], [1, 2, 0]]
CA = [[4, 1], [2, 2], [4, 1]]
Ax = [3, 0, 3]^T
```

### Inverses And Fractions

```math
[[3, 1], [-1, -3]]^{-1} = [[3/8, 1/8], [-1/8, -3/8]]
P = [[-1/2, -1, 1/2], [1, 0, 0], [0, 1, 1]]
```

### Vector Spaces

```math
Col(A) = span{[1, 2, 3]^T, [1, 1, 1]^T, [2, 1, 2]^T}
Null(A) = span{[2, -1, 1]^T}
rank(A) + nullity(A) = 3
```

### LaTeX Matrix Environments

```math
B = \begin{bmatrix}
1 & 2 \\
3 & 4
\end{bmatrix}
C = \begin{pmatrix}
x_1 & x_2 \\
y_1 & y_2
\end{pmatrix}
det(C) = \begin{vmatrix}
x_1 & x_2 \\
y_1 & y_2
\end{vmatrix}
```

## Standard Mathematical Functions

```math
det(A) != 0
lambda^2 - 3lambda + 2 = 0
x = (-b + sqrt(b^2 - 4ac)) / (2a)
\sum_{i=1}^{n} a_i x_i = b
\int_{0}^{1} x^2 dx = \frac{1}{3}
```
